# Six-Step Square Wave Commutation

## Hardware

| Component | Detail |
|---|---|
| MCU | HC32F460 (Cortex-M4, 200 MHz) |
| Gate Driver | SDH21263 (per phase: H,H=high-side ON, L,L=low-side ON, H≠L=interlock OFF) |
| Timer | TMR4 unit 3 (CM_TMR4_3), 50 kHz center-aligned triangle wave |
| PWM Pins | PB9(UH), PB8(UL), PB7(VH), PB6(VL), PB5(WH), PB4(WL) — all GPIO func2 |
| Hall Pins | PA10(Hall U), PA9(Hall V), PA8(Hall W) |
| Motor | 3 pole pairs, 3000 RPM max |

## PWM Layer: `tmr4_pwm.c/h`

Three half-bridge channels (U/V/W), each independently configurable at runtime:

| Mode | Hardware Config | H/L Behavior | SDH21263 Result |
|---|---|---|---|
| `SYNC` (through) | THROUGH PWM, both OC enabled | H and L output identical waveform | H=L → HIGH=upper ON, LOW=lower ON |
| `COMPLEMENTARY` | DEAD_TMR PWM, only low-side OC | H hardware-complement of L (with dead-time) | H≠L → interlock → both FETs OFF |

**Key functions:**
- `TMR4_PWM_Config(cfg)` — GPIO init + counter (triangle) + 3 channels OC/PWM with per-channel mode
- `TMR4_PWM_SetChannelMode(ch, mode, duty)` — Runtime mode switch (SYNC ↔ COMPLEMENTARY), used by commutation
- `TMR4_PWM_SetDuty(ch, duty)` / `SetDutyFloat(ch, pct)` — Duty cycle update
- `TMR4_PWM_StartOutput()` / `StopOutput()` / `EmergencyStop()`
- `TMR4_PWM_SetFrequency(hz)` — Runtime frequency change

**Shadow registers:** All writes go to shadow registers, transferred at counter PEAK for glitch-free 3-channel sync.

## Commutation Layer: `dev_commutation.c/h`

Six-step state table driving BLDC trapezoidal commutation via SDH21263:

```
Step 0 (UH_VL): U=SYNC(duty%),  V=SYNC(2%),   W=COMP(50%)  → U→V current
Step 1 (UH_WL): U=SYNC(duty%),  V=COMP(50%),  W=SYNC(2%)   → U→W current
Step 2 (VH_WL): U=COMP(50%),   V=SYNC(duty%), W=SYNC(2%)   → V→W current
Step 3 (VH_UL): U=SYNC(2%),    V=SYNC(duty%), W=COMP(50%)  → V→U current
Step 4 (WH_UL): U=SYNC(2%),    V=COMP(50%),  W=SYNC(duty%) → W→U current
Step 5 (WH_VL): U=COMP(50%),   V=SYNC(2%),   W=SYNC(duty%) → W→V current
```

- **SYNC(duty%):** H=L, both follow duty cycle → active phase (PWM high-side or ON low-side)
- **SYNC(2%):** Nearly always LOW → low-side ON (return path)
- **COMP(50%):** H≠L → interlock → floating phase (OFF)

**Key functions:**
- `Commutation_Init()` — All 3 phases to COMPLEMENTARY OFF
- `Commutation_Step(state, freq_hz, duty_pct)` — Apply one commutation step (0-5), lazy-update (skips if unchanged)
- `Commutation_Stop()` — All phases to COMPLEMENTARY OFF
- `COMM_STEP_UH_VL(freq, duty)` ... `COMM_STEP_WH_VL(freq, duty)` — Convenience macros

## Hall Sensor Layer: `hall_sensor_3ch.c/h`

Three Hall sensors on GPIO interrupts (both edges). On each edge:
1. Read all 3 GPIO levels → form 3-bit state code (0b000-0b111)
2. Debounce: skip if state unchanged or interval < 50 μs
3. Lookup `hall_to_step[state]` → commutation step (0-5, 0xFF=fault)
4. Call `on_step(step, dir)` callback → ISR-driven commutation

**Direction detection:** Track step sequence. Diff=+1 → forward, diff=+5 → reverse. Requires 3 consecutive confirmations.

**Alignment startup:**
1. Apply `align_step` for `align_duration_ms` (pulls rotor to known position)
2. Kick to `align_step+1` (forward) or `align_step+5` (reverse)
3. Transition to RUNNING state, ISR takes over

**RPM calculation:** `RPM = 60,000,000 / (avg_interval_us × pole_pairs × 6)` with 6-sample sliding window filter.

**Stall detection:** If no Hall pulse for `stall_timeout_ms`, set stalled flag.

## Hall State Sequence

Measured by hand-turning motor clockwise and confirmed by open-loop rotation:

```
CW Hall order:  0x03 → 0x02 → 0x06 → 0x04 → 0x05 → 0x01 → 0x03
CCW Hall order: 0x03 → 0x01 → 0x05 → 0x04 → 0x06 → 0x02 → 0x03  (reverse of CW)
```

State code formation: `(PA10 << 2) | (PA9 << 1) | PA8`

## Correct Hall-to-Step Mapping (Table 12)

Derived from open-loop CW test data. The commutation step DECREASES during CW rotation (0→5→4→3→2→1→0).

```
Hall State  →  Commutation Step
  0x03 (011) →  0  (UH_VL)
  0x02 (010) →  5  (WH_VL)
  0x06 (110) →  4  (WH_UL)
  0x04 (100) →  3  (VH_UL)
  0x05 (101) →  2  (VH_WL)
  0x01 (001) →  1  (UH_WL)
```

Table array: `{0xFF, 1, 5, 0, 3, 2, 4, 0xFF}`

Invalid states: 0x00 (0b000) and 0x07 (0b111) → map to 0xFF (fault).

## Operating Modes (comm_mode in main.c)

| comm_mode | Mode | Description |
|---|---|---|
| 0 | Coast | All 3 phases 98% SYNC → H=L≈HIGH → upper FETs ON → same potential → freewheel |
| 1 | Open-Loop Forward | Timer-driven step sequence (ramp: ~333→667 RPM, 3s), no Hall feedback |
| 2 | Open-Loop Reverse | Same as above but step direction reversed |
| 3 | Closed-Loop CW | Hall ISR-driven commutation with alignment startup (500ms) |
| 4 | Closed-Loop CCW | Same table, opposite kick direction (WIP — currently same direction as mode 3) |

## PWM Duty vs Motor Behavior

- **Driving step (SYNC, duty%):** H=L, upper FET conducts `duty%` of time → PWM torque
- **Return step (SYNC, 2%):** Nearly always LOW → lower FET conducts → GND return
- **OFF step (COMP, 50%):** H≠L → interlock → floating (both FETs off)
- **Coast (SYNC, 98%):** All 3 phases near-HIGH → all upper FETs → same potential → no current
- **Brake (SYNC, 2% on all):** Not implemented — would short all windings to GND via lower FETs

## Key Constraints

- **GBK encoding:** All `.c`/`.h` files use GBK. Use `iconv -f GBK -t UTF-8` before editing, convert back after.
- **TMR4 unit:** CM_TMR4_3 on PCLK1 (100 MHz). Period = PCLK1 / (freq × 2) for center-aligned.
- **Hall→step table:** 13 pre-computed tables in `hall_tables[14][8]`. Index 12 is the validated table from open-loop testing.
- **ISR timing:** `hall_common_handler` runs in EXINT ISR context. Keep it short — reads GPIO, does table lookup, calls `on_step` which calls `Commutation_Step`.
- **Direction tracking:** The `dir` field in hall sensor is derived from step sequence order (not physical direction). For table 12 with CW rotation, decreasing steps produce `dir=REVERSE` tracking.
